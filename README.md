## Engineering principles

* Prefer simple, explicit and maintainable designs.
* Treat observability and data quality as architecture, not add-ons.
* Automate validation, testing and deployment.
* Keep sensitive and organization-specific implementation details private.
* Publish reusable patterns rather than proprietary business logic.
* Document architectural decisions and trade-offs.
